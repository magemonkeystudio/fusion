# Fusion

If you wish to use Fusion as a dependency in your projects, Fusion is available through Maven Central
or snapshots through Sonatype.

```xml
<repository>
    <id>magemonkey-snapshots</id>
    <url>https://repo.travja.dev/snapshots</url>
</repository>
...
<dependency>
    <groupId>studio.magemonkey</groupId>
    <artifactId>fusion</artifactId>
    <version>1.0.1-R0.20-SNAPSHOT</version>
</dependency>
```
